# Ahmed Mohamed — Full Stack Web Developer Portfolio

A modern, high-performance developer portfolio built for **Ahmed Mohamed**, Full Stack Web Developer. Features interactive 3D Web Development visuals, authentic brand vector graphics, high-fidelity UI mockups, and smooth micro-interactions.

---

## 🚀 Key Features

* **3D Hero Web Development Workstation**:
  * macOS-inspired dual-pane interface with syntax-highlighted React 19 / TypeScript code and live UI metric cards (`24ms` API latency, `100/100` Lighthouse score).
  * Interactive 3D mouse parallax (`pointermove`) and floating satellite tech badges.
* **Developer Workspace & About Section**:
  * Real programming setup visual with image reveal (`blur-to-sharp`), parallax depth, and floating status indicators.
* **Official Tech Stack Ecosystem**:
  * Crisp SVG logos for HTML5, CSS3, JavaScript, TypeScript, React, Next.js, Node.js, Git, GitHub, PostgreSQL, and REST/GraphQL APIs.
* **Featured Projects with UI Mockups**:
  * 6 project cards with high-resolution UI mockups and explicit concept labels:
    1. E-Commerce Platform
    2. Business Dashboard
    3. Notes Application
    4. Digital Products Store
    5. Hotel Management System
    6. Finance Dashboard
* **Behind The Code Gallery**:
  * 6-card curated creative gallery showcasing the full lifecycle of software engineering (Coding, Design Systems, Workstation, Responsive Testing, System Architecture, Cloud Telemetry).
* **Pinned Fullscreen Experience Section**:
  * Smooth container expansion on scroll from 26% inset to 100vw full-screen with parallax background and dynamic typography.
* **Performance & Accessibility**:
  * 100% responsive, dark/light theme switching, lazy-loaded local assets (zero layout shifts), and reduced-motion support.

1. Clone or download the repository.
2. Open `index.html` in any modern web browser, or serve using any static server:
   ```bash

   # or
   python -m http.server 8000
   ```
